# Changelog

## 0.1.0

First release. Nine skills for operating your Protocol CRM from Claude, plus a
built-in connection to Protocol that sets itself up when you install.

- Review a client, onboard a new one, and run weekly check-ins
- Build and assign training programs, workouts, and nutrition plans
- Manage scheduling and triage your inbox
- Direct REST API access for bulk analysis (Claude Code only, optional)
